# Cirrusgo AI Chatbot Demo

This project is a Retrieval-Augmented Generation (RAG) chatbot built for Cirrusgo.

## Features
- Website content ingestion and cleaning
- RAG pipeline with semantic search
- AWS Bedrock integration (Titan / Claude)
- FastAPI backend
- Modular and scalable architecture

## Tech Stack
- Python
- FastAPI
- AWS Bedrock
- Amazon Titan / Anthropic Claude
- NumPy
- HTML/CSS/JS or UI

## How it works
1. Website content is scraped and cleaned into a structured knowledge base
2. User queries retrieve the most relevant chunks
3. Context is injected into an LLM prompt
4. The model returns a grounded, company-safe response
